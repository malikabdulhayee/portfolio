AI DevOps job matcher

Job boards bury real DevOps postings in listing pages, so finding relevant roles in Pakistan takes hours.

  • EventBridge Scheduler triggers a Lambda collector every six hours.
  • The collector searches the web, filters out aggregator pages and scores each posting with a language model through OpenRouter.
  • Matches go to DynamoDB with a two-day TTL. A second Lambda behind API Gateway serves them to a dashboard hosted on S3.

What I learned: the search API returned listing pages instead of postings and every score came back the same. An aggregator filter and tighter queries fixed both.

  • DynamoDB
  • EventBridge
  • API Gateway
  • S3
  • Python
